خطوات النشر على GitHub Pages (مرة واحدة)
1) في github.com اعمل Repository جديد اسمه ps-split ونوعه Public.
2) افتحه واضغط: Add file ثم Upload files.
3) اسحب كل محتويات الفولدر ده (index.html و manifest.webmanifest و sw.js وملفات icon-180.png و icon-192.png و icon-512.png) وارفعها ثم Commit changes.
4) من Settings ثم Pages: اختار Branch = main و Folder = /(root) ثم Save.
5) بعد دقيقة أو اتنين الرابط يشتغل: https://اسم-حسابك.github.io/ps-split/

تثبيت التطبيق
- أندرويد (Chrome): افتح الرابط ثم القائمة ⋮ ثم "تثبيت التطبيق".
- آيفون (Safari): افتح الرابط ثم زرار المشاركة ثم "إضافة إلى الشاشة الرئيسية".

التعديلات بعد كده
- ابعتلي التعديل المطلوب وهرجّعلك index.html جديد.
- ارفعه فوق القديم في نفس الـRepository (Add file ثم Upload files ثم Commit).
- التطبيق يتحدّث لوحده أول ما تفتحه وفيه نت.
